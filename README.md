# homebrew-tap

Homebrew formulae by [@jadewon](https://github.com/jadewon).

## Installation

```bash
brew tap jadewon/tap
```

## Formulae

| Formula | Description |
|---|---|
| [mac-claude-notifier](https://github.com/jadewon/mac-claude-notifier) | Native macOS notifications for Claude Code |
| [reclaude](https://github.com/jadewon/reclaude) | Live browser for your Claude Code sessions |

```bash
brew install jadewon/tap/mac-claude-notifier
brew install jadewon/tap/reclaude
```
